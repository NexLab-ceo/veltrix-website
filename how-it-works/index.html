02 / GETTING STARTED

Your Android becomes
the server.

Yevqo is designed around an Agent running in Termux and a browser-based workspace for managing projects.

01

Prepare Android

Use a supported Android device and install Termux from a trusted distribution source. Update its packages before setting up development tools.

pkg update && pkg upgrade
02

Connect the Yevqo Agent

The planned Agent will run inside Termux and bridge your Android environment with the Yevqo dashboard. Installation instructions will be published when it is released.

03

Manage your workspace

Use the web dashboard to view the connected device, organize projects and manage supported services. Live connection is part of the roadmap.

Important: The Yevqo Agent and live dashboard connection are not released yet. These steps describe the planned workflow, not a working installation process.
