# VELTRIX Dock — Official Landing Page

Standalone, single-page Russian landing website for VELTRIX Dock. This repository is separate from the VELTRIX Dock application, panel, and Agent source code.

## Stack

- Astro 5
- Static output
- Plain CSS (no UI framework or runtime dependencies)
- System font stack with Inter first

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The production build is generated in `dist/` and can be hosted on Cloudflare Pages or any static web server.

## Main sections

- Hero and CSS-built VELTRIX Dock panel preview
- Three-step Termux installation guide
- Product feature grid
- Redmi 9 proof-of-concept section
- GitHub, documentation, and freeware license links
