Yevqo
Agent

The planned Agent connects your Termux environment to the Yevqo workspace.

STATUS

Not released yet

The Yevqo Agent is a planned component. The installation command, supported versions and pairing flow will be published with the first release.

PURPOSE

Local device bridge

The Agent is intended to report device and project information and coordinate supported operations from the dashboard.

SECURITY

Permission-first design

The product direction is to make permissions and access boundaries visible. Do not run unofficial scripts claiming to install a Yevqo Agent.

UPDATES

Follow official releases

Use the NexLab GitHub organization and official Yevqo announcements for release information.

Product status: Yevqo is under active development. This guide describes current general Android/Termux practices and clearly marks planned Yevqo functionality.
