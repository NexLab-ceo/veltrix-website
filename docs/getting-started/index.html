Getting
started

Prepare your Android device and understand the Yevqo workflow.

01

Prepare your device

Use a supported Android device with enough free storage and a reliable power source. Android may restrict background processes, so review battery optimization settings for long-running workloads.

02

Install Termux

Install Termux from its official F-Droid or GitHub distribution. Avoid mixing Termux with add-ons from incompatible sources.

03

Update packages

Open Termux and update the package index and installed packages before adding tools.

pkg update && pkg upgrade
04

Choose a project

Start with a small static site or lightweight service. Check memory, CPU, storage and network requirements before running it continuously.

05

Connect Yevqo when available

The Yevqo Agent and live dashboard connection are still in development. Follow the release announcements for the supported installation process.

Product status: Yevqo is under active development. This guide describes current general Android/Termux practices and clearly marks planned Yevqo functionality.
